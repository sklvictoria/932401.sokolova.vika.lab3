О проекте:
Веб-страница путешественника, созданная в рамках лабораторной работы. Страница содержит информацию о навыках, посещённых странах и форму обратной связи. Основная цель работы — освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также принципы адаптивной вёрстки.

Как запустить:
Откройте файл index.html в любом браузере

# Flexbox — секция «Навыки»
- 4 карточки в ряд (display: flex, flex-wrap: wrap)
- Внутри карточки — flex-direction: column
- Прогресс-бары через <div> с width в процентах

# CSS Grid — секция «Статистика прогресса»
- 3 блока («Страны», «Города», «Фотография природного ландшафта») в сетке 3×1
display: grid, grid-template-columns: repeat(3, 1fr)

# Адаптивность
- Мета-тег viewport
- Медиа-запросы для планшетов (≤1024px) и мобильных (≤768px)
Карточки навыков: 4 → 2 → 1 колонка
Grid-дашборд: 3 → 1 колонка на мобильном
